# PFR

Twelve mathematical roots, 14 declaration spellings, 24 versioned input
projects. Provisional labels are recorded in `metadata/labels/pfr.jsonl`. All projects
have original and relocated default/explicit exports. Three historical
snapshots retain original sorryAx dependence, disclosed in project metadata.

Version/target variants and roots sharing modules are not independent
discoveries. The approximate-homomorphism pair intentionally reuses formal
source with different own-version blueprint targets. All PFR projects share
one repository split; KL and rho share a mechanism group.

See [index.csv](index.csv), [review and limitations](https://github.com/MechMath/PaperLeanBench/blob/8012191c69c75a008356ba7b7bd422f0d57d2884/reports/pfr-admission/README.md)
and [explicit upstream evidence](../../metadata/upstream-evidence/pfr.jsonl). Two unextracted historical
leads are deferred outside this dataset. On 2026-11-09, both independent-blocks
snapshots gained an independent probability-text target with arbitrary block index
set and finite disjoint coordinate blocks. Both are provisionally aligned, using
the finite-subfamily characterization for the earlier finite-index theorem.
Old notices, source evidence and new input hashes are retained in
`reports/undetermined-review-2026-11-09/`; the formal sources are unchanged.
